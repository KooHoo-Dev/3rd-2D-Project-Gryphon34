# 이동과 길찾기 시스템 기획서

---

## 1. 목적

플레이어가 타일을 클릭하면 농부가 **스스로 경로를 찾아** 그곳까지 걸어간다.

이 게임에는 방향키 조작이 없다. 클릭 한 번이 곧 "저기로 가서 저 일을 해라"라는 명령이다.

---

## 2. 용어

| 용어 | 코드 | 뜻 |
|---|---|---|
| 경로 | `List<Tile> path` | 출발 타일에서 목표 타일까지 밟고 갈 타일들 |
| G 비용 | `GCost` | 출발점에서 여기까지 **실제로** 지나온 이동 비용의 합 |
| H 비용 | `HCost` | 여기서 목표까지 **예상되는** 비용 (휴리스틱) |
| F 비용 | `FCost` | `G + H`. 이 타일을 거치는 경로의 총 예상 비용 |
| 열린 목록 | `openList` | 아직 살펴봐야 할 후보 타일들 |
| 닫힌 목록 | `closedList` | 이미 살펴본 타일들 |
| 휴리스틱 | — | 목표까지 얼마나 남았는지에 대한 **추측**. 실제보다 크면 안 된다 |
| 예약 행동 | `PendingAction` | 도착한 뒤에 실행할 일 |

---

## 3. 동작 규칙

### 3.1. 경로 계산 — A\*

```
F = G + H

G : 출발 타일에서 여기까지 지나온 타일들의 MoveCost 합
H : 맨해튼 거리 x 최소 이동 비용
```

| 항목 | 규칙 |
|---|---|
| 이동 방향 | **4방향(상하좌우)만. 사선 금지** |
| 휴리스틱 | 맨해튼 거리 `abs(dx) + abs(dy)` |
| 통과 불가 | 물 · 바위 · 울타리 |
| 열린 목록 | `List` + 최솟값 탐색 |
| 같은 F일 때 | H가 작은 쪽을 먼저 본다 (목표에 가까운 쪽) |

### 3.2. 이동

- 경로를 찾으면 **한 타일씩** 이동한다. 중간에 멈추지 않는다
- 이동 방향으로 애니메이터 파라미터(`DirY` · `IsMoving`)를 갱신한다
- 좌우 이동은 `lr` 클립을 쓰고 `flipX` 로 방향을 만든다
- 손에 무언가 들고 있으면(`IsCarrying`) 운반 클립 세트로 바뀐다

### 3.3. 클릭 = 이동 + 도착 시 행동

클릭 한 번에 **목적지와 할 일이 함께** 정해진다.

```
클릭한 타일을 본다
  > 무슨 일을 할 수 있는 타일인가 판단 (흙이면 밭 갈기, 다 자란 작물이면 수확 …)
  > 그 타일까지 경로를 찾는다
  > 이동한다
  > 도착하면 예약해 둔 행동을 실행한다
```

행동 대상 타일 자체가 통과 불가일 수 있다(예: 창고). 
그럴 때는 **인접한 타일까지** 이동한다.

### 3.4. 이동 중 재클릭

이동하는 도중에 다른 곳을 클릭하면 **현재 경로를 버리고 새 경로로 바꾼다.**
예약해 둔 행동도 함께 교체된다. 이전 명령은 남지 않는다.

### 3.5. 일시정지 중

- 움직이지 않는다
- 재개하면 그 경로로 출발한다

## 4. 수치

**단일 출처 : `StreamingAssets/Table/MiniFarm/config.json`**

이동 비용은 타일이 가진다 -> [01. 월드와 타일](<01. 월드와 타일.md>) `tiles.tsv`

| 키 | 뜻 |
|---|---|
| `MoveSpeed` | 타일 하나를 지나는 데 걸리는 게임 시간 |
| `MinMoveCost` | 휴리스틱 계산에 쓰는 최소 이동 비용 |

> `MinMoveCost` 는 `tiles.tsv` 의 최솟값과 같아야 한다.
> 이보다 크게 잡으면 휴리스틱이 실제 비용을 넘어서고, **A\* 가 최단 경로를 놓친다.**

### 밸런스 의도 (예시임 이거)
- 이동이 너무 빠르면 창고 위치 선택이 무의미해진다. 
- 왕복이 부담으로 느껴질 만큼은 느려야 한다

## 5. 예외와 실패 처리

**사용자 입력으로 인한 실패 — 정상 처리한다**

| 상황 | 처리 |
|---|---|
| 통과 불가 타일을 클릭 | 이동하지 않고 피드백만 준다 |
| 경로가 없다 (막혀 있다) | 이동하지 않고 피드백만 준다. `FindPath` 는 `null` 을 반환한다 |
| 이미 서 있는 타일을 클릭 | 이동을 건너뛰고 행동만 실행한다 |
| 이동 중 재클릭 | 경로를 교체한다 (§3.4) |
