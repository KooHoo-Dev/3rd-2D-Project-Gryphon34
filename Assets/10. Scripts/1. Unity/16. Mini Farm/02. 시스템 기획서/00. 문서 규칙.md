# 시스템 기획서 — 문서 규칙

이 폴더의 문서는 **시스템 하나씩**을 맡는다.
새로 쓰거나 고칠 때 아래 규칙을 지킨다.

---

## 1. 문서 하나 = 시스템 하나 = 코드/그래픽 에셋 폴더 하나

| 문서 | 폴더           |
|---|----------------|
| `01. 월드와 타일.md` | `00. World`    |
| `02. 이동과 길찾기.md` | `01. Movement` |
| … | …              |

---

## 2. 골격 (6절 고정)

```markdown
# {시스템명} 시스템 기획서

> 관련 코드 : `{폴더}` · 관련 표 : `{파일}` · 최종 수정 : YYYY-MM-DD

## 1. 목적
## 2. 용어
## 3. 동작 규칙
## 4. 수치
## 5. 예외와 실패 처리
## 6. 다른 시스템과의 관계
```

| 절 | 무엇을 쓰나 |
|---|---|
| 1. 목적 | 3~5줄. **"이게 없으면 게임이 어떻게 되는가"** 로 쓰면 잘 나온다 |
| 2. 용어 | 표. 한글 용어와 코드 식별자를 나란히 둔다 |
| 3. 동작 규칙 | 본문. 순서가 있으면 코드블록, 분기가 있으면 표 |
| 4. 수치 | **표 파일을 가리킨다.** 아래 §3 규칙 |
| 5. 예외와 실패 처리 | 사용자 입력 실패와 데이터 오류를 **나눠서** 적는다 |
| 6. 다른 시스템과의 관계 | 의존 / 피의존을 나눠 적는다 |

---

## 3. 수치는 표 파일이 단일 출처

**문서에 값을 복사하는 것을 지양.** 
문서와 표가 어긋나는 사고가 여기서 난다.

문서가 하는 일은 **어떤 표의 어떤 컬럼을 쓰는지 알려 주는 것**이다.
다만 열 구성이 눈에 보여야 하므로 **2~3행만 발췌**해 예시로 보여준다.

```markdown
## 4. 수치

**단일 출처 : `StreamingAssets/Table/MiniFarm/crops.tsv`**
값을 고칠 때는 이 문서가 아니라 표를 고친다. 아래는 열 구성을 보여주는 발췌다.

| ID | Name | SeedPrice | GrowDays | WaterNeed | Yield |
|---|---|---|---|---|---|
| 1 | 순무 | 20 | 2 | 1 | 1 |
| 2 | 감자 | 40 | 3 | 2 | 2 |

> 전체 행은 표 파일에 있다. 위 두 행은 형태를 보여주기 위한 예시다.
```

- 발췌는 **2~3행까지.** 전부 옮기면 그 순간 이중 관리가 시작된다
- 열 이름은 **DTO 필드명과 정확히 같아야 한다**
- 키 이름 관례 — 자기 키는 `ID`, 남의 표를 가리키면 `{대상}ID` (예: `HarvestItemID`)
- 밸런스 **의도**는 값이 아니라 문장으로 쓴다 -> "비쌀수록 회수가 느리고 이익이 크다"

---

## 4. §6이 설계 검토 도구

의존 관계를 적다 보면 잘못이 드러난다.

- **순환 참조** — "A가 B를 알고 B도 A를 안다"가 적히면 그 자리에서 잡는다
- **층 위반** — 아래층이 위층을 알고 있으면 이벤트로 뒤집어야 한다는 신호다

```markdown
## 6. 다른 시스템과의 관계

**내가 기대는 것**
- 월드와 타일 : 타일의 이동 비용과 통과 가능 여부를 읽는다

**나에게 기대는 것**
- 농사 : 도착 후 행동을 실행하려고 이동 완료를 기다린다
```

## 5. 공통 서식

| 항목 | 규칙                                                                 |
|---|----------------------------------------------------------------------|
| 문체 | 평서체 (`~한다`)                                                     |
| 절 구분 | `---`                                                                |
| 표 셀 안 파이프 | 쓰지 않는다. 백틱으로 감싸도 표가 깨진다 -> `abs(dx)`                |
| 링크 | 공백 경로는 꺾쇠 ->`[제목](<01. 월드와 타일.md>)`                    |
| 용어 | 이 폴더 안에서 같은 것을 같은 말로 부른다. 흔들리면 §2 용어표에 추가 |
