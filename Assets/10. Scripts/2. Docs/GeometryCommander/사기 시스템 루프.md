**체력 및 사기 시스템 작동 규칙**



**체력 시스템**



\* 적의 기본 공격력에 의해 정직하게 감소하며 누적되는 물리적인 목숨입니다.



\* 상성 관계에 따라 유리한 상성의 공격을 받으면 50%의 데미지만 입고 불리한 상성에게 맞으면 200%의 데미지를 입습니다.



\* 체력이 0이 되어 파괴된 유닛은 시각적 파티클을 남기며 사망.



**사기 시스템**



\* 유닛의 최대 사기는 100입니다. 일반적인 적에게 공격받을 때는 사기가 감소하지 않거나 1만 감소하여 정신력을 유지합니다.



\* 자신에게 상성상 불리한 천적 유닛에게 피격될 때는 사기가 한 번에 10씩 크게 감소합니다.



\* 유닛의 개별 사거리와 별개로 설정된 고정 원형 범위인 사기 영향 사거리 안에서 다른 아군 유닛이 체력 고갈로 파괴되면 본인의 현재 남은 사기 수치의 절반이 즉시 증발합니다.





\* 사기는 실시간 전황에 따라 변동하며 포드를 낙하시켜 인원이 충당되거나 적을 처치하면 다시 차오릅니다.



\* 사기 수치가 0에 도달한 유닛은 공격 능력을 완전히 상실합니다. 이 유닛은 주변 아군에게 사망 사기 페널티를 주지 않는 안전한 상태로 전환되며 2초 동안 전술 스크린에서 서서히 흐려지다가 완전히 소멸합니다.





**체력 시스템 (피격 이벤트 발생 시 실행)**

if (체력 <= 0) 

{

&#x20;   시각적 파티클 생성();

&#x20;   사망 처리();

}

else 

{

&#x20;   switch (공격해온 적의 상성) 

&#x20;   {

&#x20;       case 동일\_상성:

&#x20;           체력 -= 적의 공격력;

&#x20;           break;

&#x20;       case 천적\_상성(불리):

&#x20;           체력 -= 적의 공격력 \* 2;

&#x20;           break;

&#x20;       case 우세\_상성(유리):

&#x20;           체력 -= 적의 공격력 \* 0.5;

&#x20;           break;

&#x20;   }

}



**사기 시스템 (피격 및 주변 아군 사망 이벤트 발생 시 실행)**

if (사기 <= 0) 

{

&#x20;   공격 능력 상실 상태로 전환();

&#x20;   2초 동안 서서히 흐려진 후 소멸();

}

else 

{

&#x20;   switch (공격한 적의 병종) 

&#x20;   {

&#x20;       case 일반\_적에게\_공격당함:

&#x20;           사기 -= 1;

&#x20;           break;

&#x20;       case 천적에게\_공격당함:

&#x20;           사기 -= 10;

&#x20;           break;

&#x20;       case 사거리\_내\_아군\_체력\_고갈\_사망:

&#x20;           사기 -= 남은 사기 / 2;

&#x20;           break;

&#x20;   }

}
