**플레이어 유닛 전투 로직 루프**



\* 게임 시작 시 기본 배치된 유닛들이나 포드에서 막 낙하했을 때 주변에 적이 없는 유닛들은 가장 먼저 자신의 사거리에 들어온 적들을 우선적으로 공격합니다.



\* 근접 유닛은 사거리 내에 들어온 적들 중 자신과 가장 가까운 거리에 있는 적을 실시간으로 추적해 공격합니다.



\* 원거리 유닛은 현재 공격하고 있던 대상이 죽거나 사거리 밖으로 벗어났을 때 사거리 내에 존재하는 적들 중 남은 체력이 가장 적은 유닛을 탐색하여 다음 타겟으로 잡습니다.



**적군 유닛 전투 로직 루프**



\* 전장에 생성된 직후 최종 목적지인 중앙 베이스 캠프를 향해 무조건 직진합니다.



\* 이동하는 도중에 플레이어 유닛의 사거리에 들어가더라도 멈추지 않고 오직 베이스 캠프만 보며 걸어갑니다.



\* 오직 플레이어의 근접 유닛이 자신의 진격 경로를 물리적으로 가로막아 더 이상 전진할 수 없을 때만 발걸음을 멈춥니다.



\* 길을 막아선 플레이어 유닛을 타겟으로 고정하고 그 유닛이 파괴될 때까지 제자리에서 공격을 시작합니다.



\* 가로막던 플레이어 유닛이 파괴되거나 사기 저하로 소멸하여 앞길이 열리면 지체 없이 다시 베이스 캠프를 향해 진격을 재개합니다.





// 플레이어 유닛 전투 로직
```csharp
if (근접\_유닛)
{
   if (최초_조우_고정_상태 == true)
   {
       if (현재_타겟 == 없음 || 현재_타겟.체력 <= 0 || 적과의_거리(현재_타겟) > 사거리) 
       {
           현재_타겟 = 사거리_내_가장_가까운_적_찾기(); 
       }
       if (현재_타겟 != 없음 && (현재_타겟.체력 <= 0 || 적과의_거리(현재_타겟) > 사거리)) 
       {
           현재_타겟 = 없음;
           최초_조우_고정_상태 = false; 
       }
   }
   else 
   {
       현재_타겟 = 사거리_내_가장_가까운_적_찾기();
   }
   if (현재_타겟 != 없음) 
   {
       공격_실행(현재_타겟); 
   }
}
else if (원거리_유닛)
{
   if (현재_타겟 == 없음 || 현재_타겟.체력 <= 0 || 적과의_거리(현재_타겟) > 사거리) 
   {
       if (최초_조우_고정_상태 == true)
       {
           현재_타겟 = 사거리_내_가장_먼저_들어온_적_찾기(); 
           if (현재_타겟 != 없음)
           {
               최초_조우_고정_상태 = false; 
           }
       }
       else 
       {
           현재_타겟 = 사거리_내_체력이_가장_적은_적_찾기();
       }
   }
   if (현재_타겟 != 없음) 
   {
       공격_실행(현재_타겟); 
   }
}
```
