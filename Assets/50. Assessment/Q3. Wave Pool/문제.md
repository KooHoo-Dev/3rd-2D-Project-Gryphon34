# 문제 3 — 웨이브와 오브젝트 풀

| | |
|---|---|
| 영역 | 통합 · 상태 오염 |
| 제한 시간 | 30분 |
| AI 도구 | **사용 허용** (프롬프트와 처리 과정을 관찰한다) |

---

## 1. 시나리오

적이 웨이브 단위로 나오는 스테이지다. 적을 클릭하면 한 대 때린다. 살아 있는 적이 전부 사라지면 다음 웨이브로 넘어가고, 웨이브마다 적이 한 마리씩 늘어난다. 적은 매번 새로 만들지 않고 오브젝트 풀에서 꺼내 쓰고 되돌려 받는다. `R` 키로 스테이지를 처음부터 다시 시작한다.

## 2. 재현 절차

1. `Assets/50. Assessment/Scenes/Q3. Wave Pool.unity` 를 연다.
2. 재생(Play)한다. → `웨이브 1 시작 — 적 3마리 소환`
3. 적 3마리를 각각 3번씩 클릭해 처치한다.
4. 웨이브 2 로그가 뜨는 순간의 Console 과 화면을 확인한다.
5. **남은 적을 처치하지 말고** 그 상태에서 `R` 을 누른다.
6. 재시작 직후의 첫 로그를 확인한다.

## 3. 관찰되는 증상

| 단계 | 기대 동작 | 실제 동작 |
|---|---|---|
| 웨이브 1 | 적 3마리, 각 3번 클릭에 처치 | 같음 (정상) |
| 웨이브 2 (절차 4) | 적 4마리, 각 3번 클릭에 처치 | `적 4마리 소환` 로그는 뜨지만, **클릭하지 않은 3마리가 즉시 처치 처리**되고 1마리만 남는다 |
| `R` 재시작 (절차 6) | `웨이브 1 시작 — 적 3마리 소환` | `웨이브 3 시작 — 적 5마리 소환` |

재시작 후 소환된 적들은 다시 3번 클릭해야 죽는다.

## 4. 제공 코드

| 파일 | 역할 |
|---|---|
| `Q3. Wave Pool/Scripts/PooledEnemy.cs` | 적 체력과 피격 처리 |
| `Q3. Wave Pool/Scripts/EnemyPool.cs` | 적 오브젝트 풀 |
| `Q3. Wave Pool/Scripts/WaveRunner.cs` | 웨이브 진행과 재시작 |
| `Q3. Wave Pool/Scripts/PlayerStrike.cs` | 클릭 판정 |

## 5. 씬 구성

```
Q3. Wave Pool
├── Main Camera
├── PlayerStrike
├── EnemyPool
├── SpawnPoints
│   ├── Point_0                (-5, 2)
│   ├── Point_1                (-3, 2)
│   ├── Point_2                (-1, 2)
│   ├── Point_3                ( 1, 2)
│   ├── Point_4                ( 3, 2)
│   └── Point_5                ( 5, 2)
└── WaveRunner
```

### 인스펙터 값

| 오브젝트 | 컴포넌트 | 필드 | 값 |
|---|---|---|---|
| PlayerStrike | Player Strike | World Camera | Main Camera |
| EnemyPool | Enemy Pool | Enemy Prefab | `Prefabs/Q3 PooledEnemy.prefab` |
| EnemyPool | Enemy Pool | Prewarm Count | 4 |
| WaveRunner | Wave Runner | Pool | EnemyPool |
| WaveRunner | Wave Runner | Spawn Points | Point_0 ~ Point_5 (6개) |
| WaveRunner | Wave Runner | Base Enemy Count | 3 |
| Q3 PooledEnemy.prefab | Pooled Enemy | Max Health | 3 |

## 6. 과제

1. 증상의 **원인을 규명**한다. 원인은 **두 개**이고, 서로 다른 결함이다.
2. 원인을 제거하는 방향으로 **수정**한다. 증상만 가리는 수정은 감점한다.
3. 아래 내용을 설명하는 주석을 `WaveRunner.cs`에 적는다
   - 각각 무엇이 원인이었는가
   - 왜 웨이브 1 에서는 증상이 나타나지 않았는가

시간 내에 고치지 못해도 **"여기까지 좁혔고 이 지점이 의심된다"** 를 근거와 함께 말할 수 있으면 점수가 인정된다.
