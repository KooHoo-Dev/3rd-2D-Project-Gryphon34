# 문제 2 — 근접 전투 스테이지

| | |
|---|---|
| 영역 | Unity 런타임 |
| 제한 시간 | 25분 |
| AI 도구 | **사용 허용** (프롬프트와 처리 과정을 관찰한다) |

---

## 1. 시나리오

탑다운 2D 스테이지다. 플레이어를 움직여 적에게 붙고, 스페이스로 사거리 안의 적을 전부 때린다. 적은 체력이 0이 되면 사라지고, 스테이지에 배치된 적을 모두 처치하면 클리어 로그가 뜬다.

## 2. 재현 절차

1. `Assets/50. Assessment/Scenes/Q2. Melee Combat.unity` 를 연다.
2. 재생(Play)한다.
3. 방향키(또는 WASD)로 왼쪽 적 `Enemy_A` 에 붙는다.
4. 스페이스를 3번 누른다. → 처치된다.
5. 오른쪽 적 `Enemy_C` 로 이동해 똑같이 3번 누른다. → 처치된다.
6. 가운데 적 `Enemy_B` 로 이동해 스페이스를 **10번 이상** 눌러 본다.
7. Console 전체를 확인한다.

## 3. 관찰되는 증상

| | 기대 동작 | 실제 동작 |
|---|---|---|
| Enemy_A · Enemy_C | 스페이스 3번에 처치 | 같음 (정상) |
| Enemy_B | 스페이스 3번에 처치 | 몇 번을 눌러도 **피격 로그가 하나도 뜨지 않는다** |
| 처치 로그의 "남은 적" | 2마리 → 1마리 → 0마리 | 3마리 → 2마리 (실제 남은 수보다 하나 많다) |
| 3마리 처치 후 | `스테이지 클리어` 출력 | 출력되지 않는다 |

플레이어가 `Enemy_B` 위를 그냥 지나간다는 점도 눈에 띈다.

## 4. 제공 코드

| 파일 | 역할 |
|---|---|
| `Q2. Melee Combat/Scripts/PlayerMover.cs` | 플레이어 이동 |
| `Q2. Melee Combat/Scripts/MeleeAttackZone.cs` | 사거리 안의 적 추적과 공격 입력 |
| `Q2. Melee Combat/Scripts/Enemy.cs` | 적 체력과 피격 처리 |
| `Q2. Melee Combat/Scripts/StageGoal.cs` | 처치 수 집계와 클리어 판정 |

## 5. 씬 구성

```
Q2. Melee Combat
├── Main Camera
├── StageGoal
├── Player                     (0, -2)
│   └── AttackZone
└── Enemies
    ├── Enemy_A                (-3, 1.5)
    ├── Enemy_B                ( 0, 1.5)
    └── Enemy_C                ( 3, 1.5)
```

`Enemy_A` · `Enemy_B` · `Enemy_C` 는 모두 `Prefabs/Q2 Enemy.prefab` 의 인스턴스다.
`AttackZone` 은 트리거 콜라이더이며, 여기에 `MeleeAttackZone` 이 붙어 있다.

### 인스펙터 값

**이 문제에서는 인스펙터 값을 문서로 옮기지 않았다.** 씬에서 직접 확인하라.

## 6. 과제

1. 증상의 **원인을 규명**한다. 원인은 **두 개**다.
2. 원인을 제거하는 방향으로 **수정**한다. 증상만 가리는 수정은 감점한다.
3. 아래의 내용을 설명하는 주석을 `StageGoal.cs`에 적는다.
   - 각각 무엇이 원인이었는가
   - 왜 그 원인이 이런 증상으로 나타났는가

시간 내에 고치지 못해도 **"여기까지 좁혔고 이 지점이 의심된다"** 를 근거와 함께 말할 수 있으면 점수가 인정된다.
